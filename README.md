# NPC-Turns

One-sentence description of what it does.

## The Problem

When playing tabletop role-playing games, I noticed that it could 
take a long time for the game master to finish the turns of all of
the non-player characters in combat, which really slows down the
game. I plan on making a program that will speed up the turns for
the game master, so the players don't have to wait as long.

## How It Works

The java program can automatically roll all of the dice and make the
calculations for the game master during his turns in combat. All that
needs to be done is to tell the program who is moving and it will make
all the necessary rolls.

## Tech Stack

- **Language:** Java
- **Libraries:** java.util.random, java.io.*
- **External tools:** None
